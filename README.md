# 日本継目補修協会（JSRA）

ブラウザで遊べるホラーノベルゲームです。スマートフォンとPCに対応しています。

閉鎖されたショッピングモールの「継目」を補修するアルバイトや職員の端末を、謎の依頼人に頼まれて覗いていく物語です。

## 遊び方

GitHub Pages で公開しているページを開いてください。進行状況はお使いのブラウザの中にだけ保存されます。

## ご注意

- 本作はフィクションです。実在の人物・団体・施設・求人・アプリとは関係ありません。
- 作中に登場する求人・アプリ・広告は、すべて架空のものです。
- ホラー表現を含みます。「閲覧注意」と表示される記録には、強めの恐怖表現があります。
- 背景・キャラクターなどの画像の多くは、生成AI（Google Gemini ほか）で作成しています。
